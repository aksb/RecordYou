# RecordYou (Modified Edition)

English | [中文](README.md)

A privacy-focused audio/screen recording app featuring a Floating Control Ball.

> **Note**: This repository is forked from [you-apps/RecordYou](https://github.com/you-apps/RecordYou) and modified based on its source code.
> - **Added Floating Ball Control**: Quick access to audio and screen recording via an on-screen floating ball, eliminating the need to frequently pull down the notification bar.
> - **Audio Fixes**: Resolved potential audio glitches occurring during background "screen recording + microphone recording" on certain Android devices.
> - **UI Refinement**: Re-adjusted and optimized parts of the original user interface for clearer operational logic and better daily usability.

## 📦 Installation

### Option 1: APK Only
Simply download and install the APK to start using the app.

### Option 2: APK + Magisk Module
If your device is rooted and running Magisk:
After installing the APK, flash the companion **Magisk Module** to gain:
🔊 **Internal System Audio Recording Support**
Additionally, the Magisk module includes a small bonus feature: 🛡️ **Boot Autostart / Keep-Alive Command**, reducing the chance of the background process being killed by system memory management.
